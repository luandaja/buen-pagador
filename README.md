# El Buen Pagador

Sube la foto del equipo y marca quién ya pagó la cancha. Exporta una imagen o comparte un link de solo lectura.

```bash
pnpm install
pnpm dev
```

Para los links compartidos en producción, conecta Upstash Redis al proyecto en Vercel (`KV_REST_API_URL`, `KV_REST_API_TOKEN`).
